# NumPy Data Explorer 📊

A Python-based data analysis project that explores company productivity by processing employee production data using NumPy. The project demonstrates numerical calculations, file handling, array manipulation, and object-oriented programming.

## 🚀 Features

- **Data Loading:** Reads employee production data from a text file (`company.txt`).
- **Company Productivity Analysis:** Calculates the total number of products produced by each company.
- **Maximum Productivity:** Identifies the company with the highest total production.
- **Minimum Productivity:** Identifies the company with the lowest total production.
- **Average Employee Productivity:** Calculates the average number of products produced per employee in each company.
- **Overall Average:** Calculates the average production per employee across all companies.
- **Object-Oriented Programming:** Uses a custom `IntArray` class to perform additional array-related operations.

## 🛠️ Technologies Used

- Python
- NumPy
- File Handling
- Object-Oriented Programming (OOP)

## 📈 Analysis and Calculations

The application performs the following analyses:

1. Loads employee production data into NumPy arrays.
2. Calculates total production for each company.
3. Identifies the highest- and lowest-performing companies based on total production.
4. Calculates the average employee production for each company.
5. Computes the overall average production per employee across all companies.
